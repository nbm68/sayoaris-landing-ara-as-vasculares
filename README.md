## Despliegue

Esta landing está configurada para desplegarse en **GitHub Pages**.

### Activar GitHub Pages

1. Sube este repositorio a GitHub
2. Ve a **Settings** → **Pages**
3. En "Branch" selecciona `main` (o `master`) y guarda
4. GitHub te dará una URL como: `https://tu-usuario.github.io/sayoaris-landing-arañas-vasculares/`
